# Synthetic examples

These files show the shape of `gitlab-tools` output. Every organization, project, milestone, issue, person, URL, and date is fictional.

- [`milestone-example.md`](milestone-example.md) follows the Milestone Markdown renderer.
- [`issue-example.md`](issue-example.md) follows the Issue Markdown renderer.
- [`repository-tree.txt`](repository-tree.txt) shows namespace-preserving Repository output.

Do not copy credentials or real internal server names into examples or bug reports.
