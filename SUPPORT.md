# Support

## Installation and usage

Read the [user guide](USER_GUIDE.md) first. It covers Python and Git installation, online and offline Wheel installation, configuration, Windows BAT launchers, both exporters, and common errors.

If the guide does not resolve the problem, open a [Bug report](https://github.com/sgh6688/gitlab-tools/issues/new?template=bug_report.yml) with a minimal synthetic reproduction.

Before posting publicly, remove:

- GitLab tokens and authorization headers;
- private GitLab URLs and internal IP addresses;
- organization, group, project, milestone, and user names;
- local usernames and private filesystem paths;
- exported production content.

## Feature requests

Use the [Feature request](https://github.com/sgh6688/gitlab-tools/issues/new?template=feature_request.yml) form. Describe the workflow and desired outcome. Open an Issue before starting a large compatibility or CLI change.

## Security vulnerabilities

Use [private vulnerability reporting](https://github.com/sgh6688/gitlab-tools/security/advisories/new). Do not disclose suspected vulnerabilities in public Issues. See [SECURITY.md](SECURITY.md) for scope and supported versions.
